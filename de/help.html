Benutzerhandbuch für ShiftAlarm

Version 1. Datum: 23. Juni 2026.

1. Erster Start

Öffnen Sie die Anwendung, wählen Sie die gewünschte Sprache, prüfen Sie die Berechtigungen und konfigurieren Sie die Zuverlässigkeit der Alarme. Auf manchen Geräten kann es außerdem erforderlich sein, Hintergrundaktivität zuzulassen und Akkubeschränkungen aufzuheben.

2. Alarme

Erstellen Sie reguläre Alarme, an bestimmten Wochentagen wiederholte Alarme, Datumsalarme und schichtbezogene Alarme. Prüfen Sie bei wichtigen Alarmen die Benachrichtigungen, die Berechtigung für exakte Alarme und die Akkubeschränkungen.

3. Geo-Alarme

Erstellen Sie einen Geo-Alarm durch langes Drücken auf die Karte. Verwenden Sie für eine höhere Zuverlässigkeit einen Radius von 800–1000 m und erlauben Sie den genauen Standort sowie den Hintergrundstandort.

4. Schichten

Erstellen Sie einen aktiven Schichtplan. Schichtbezogene Alarme und Kalender-Widgets verwenden den aktiven Schichtplan und berücksichtigen Abweichungen für einzelne Tage.

5. Notizen und Erinnerungen

Verwenden Sie Textnotizen, Listen, Ereignisse, Erinnerungen, Audionotizen und Sprachtranskription. Offline-Sprachmodelle können in den Einstellungen heruntergeladen werden.

6. Widgets

Fügen Sie dem Android-Startbildschirm ein Heute-Widget oder ein Kalender-Widget hinzu. Widgets zeigen die nächstliegenden Informationen an, werden automatisch aktualisiert und verfügen zusätzlich über eine Schaltfläche zur manuellen Aktualisierung.

7. Sicherungskopien

In den Einstellungen können Sie eine Sicherungskopie auf dem Telefon speichern oder sie über das Android-Freigabemenü teilen.

8. Diagnose

Funktioniert eine Funktion nicht korrekt, öffnen Sie das zugehörige Diagnoseprotokoll und kopieren oder senden Sie es zusammen mit einer Problembeschreibung an den Entwickler.
