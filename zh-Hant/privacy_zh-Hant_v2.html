ShiftAlarm 隱私權政策

版本 2。日期：2026年6月29日。

1. 資料處理的一般原則

ShiftAlarm 主要採用離線優先（offline-first）模式。主要使用者資料在使用者裝置本機建立、處理和儲存。除非使用者自行透過支援請求、匯出、電子郵件、即時通訊工具、雲端儲存、應用程式商店或其他由使用者選擇的方式傳送資料，否則開發者不會自動取得這些資料。

截至本版本日期，本應用程式不使用廣告網路、自有帳戶系統、伺服器端身分驗證、Firebase Analytics、Google Analytics、Crashlytics 或 AdMob；如有變化，將在本政策的更新版本中明確說明。

2. 可能儲存在本機的資料

根據使用者使用的功能，本應用程式可能在裝置上儲存下列資料：

  • 應用程式設定、語言、主題、小工具參數和使用者偏好；
  • 一般鬧鐘、輪班連動鬧鐘、時間、重複設定、鈴聲、振動、稍後提醒、漸強（fade-in）及相關參數；
  • 輪班計劃、輪班模板、日曆覆蓋設定、休息日和使用者自訂標記；
  • 地理圍欄鬧鐘：座標、半徑、進入或離開事件類型、地址、地點名稱、書籤、計劃和觸發狀態；
  • 筆記、事件、提醒、清單、文字區塊和相關日期；
  • 音訊筆記、語音錄音和文字轉錄；
  • 計時器、碼錶、世界時鐘，以及相關功能啟用時儲存的部分操作紀錄；
  • 薪資、獎金、扣款、罰款、報告和相關計算的參數；
  • 診斷日誌、技術事件、權限資訊、錯誤和功能狀態；
  • 使用者手動建立的備份。

3. 使用者可能傳送給開發者的資料

如果使用者透過 support@insdeco.ru 聯絡支援，開發者可能收到使用者的電子郵件地址、電子郵件中的姓名或簽名、請求正文、附件、螢幕截圖、備份檔案、診斷報告，以及裝置型號、Android 版本、應用程式版本、事件時間和問題描述等資訊。

這些資料僅在使用者主動操作時傳送。使用者應在傳送前自行檢查電子郵件和附件的內容。

4. 處理目的

資料用於實現應用程式功能、儲存使用者設定、觸發鬧鐘和提醒、執行地理圍欄鬧鐘、顯示筆記和小工具、建立備份、診斷錯誤、處理支援請求、提高應用程式穩定性、履行法律要求，以及保護開發者和使用者的權利。

根據適用法律，處理的法律依據可能包括履行使用者協議、使用者主動操作、對特定權限的同意、提供支援和保障安全的合法利益，以及履行法定義務。

5. 裝置權限

本應用程式僅可能請求相應功能所需的權限：

  • 通知——用於鬧鐘、計時器、提醒和服務通知；
  • 精準鬧鐘及鬧鐘相關權限——用於在使用者設定的時間觸發；
  • 使用應用程式時的定位權限——用於選擇地點、顯示地圖和設定地理圍欄鬧鐘；
  • 背景定位權限——用於在應用程式未開啟時執行地理圍欄鬧鐘；
  • 麥克風——用於音訊筆記、語音輸入和語音辨識；
  • 網際網路——用於下載語言包、法律文件、說明資料和離線轉錄模型、地圖和網路功能；
  • 透過系統檔案選擇器存取檔案——用於匯出和匯入備份；
  • 電池和背景執行設定——用於提高鬧鐘、通知和地理圍欄鬧鐘的可靠性。

使用者可以在 Android 設定中撤銷權限。撤銷後，部分功能可能無法使用或受到限制。

6. 地理位置與地圖

位置資料用於在地圖上選擇位置、儲存地理圍欄鬧鐘、判斷進入或離開指定區域、顯示地址和建立地點書籤。除非使用者自行匯出或傳送這些資料，座標和地理圍欄鬧鐘參數均儲存在裝置本機。

在使用地圖和地址辨識功能時，應用程式可能存取地圖和地理編碼元件，包括 osmdroid/OpenStreetMap、Nominatim 反向地理編碼、系統 Android Geocoder 或裝置上可用的其他服務。這些服務可能接收請求技術資料、IP 位址、座標或顯示地圖和判定地址所必需的其他資訊。

7. 音訊、離線與線上轉錄

音訊筆記和轉錄文字由使用者主動建立；如果使用者自行錄入相關內容，其中可能包含個人資料或敏感資料。除非使用者匯出或傳送，否則這些資料儲存在裝置本機。

離線轉錄可能使用下載到本機的語音辨識模型。下載這些模型時，遠端伺服器可能取得連線相關技術資料，例如 IP 位址和請求資訊。

線上語音辨識可能使用由裝置、製造商、使用者或作業系統選擇的 Android 系統語音辨識服務。在此情況下，音訊資料和技術資訊可能被傳送至所選語音辨識服務，並依該服務的規則進行處理。ShiftAlarm 的開發者無法控制該系統服務的政策。

8. 網路下載與外部來源

應用程式可能使用網際網路下載語言包、資訊清單（manifest）檔案、法律文件、說明資料和離線轉錄模型，包括從 GitHub 或應用程式中指定的其他遠端來源下載。執行這些請求時，遠端伺服器可能接收 IP 位址、請求日期和時間、檔案路徑、連線資訊及其他標準技術資料。

對於應用程式內已實作完整性驗證機制的檔案，可以使用 SHA-256 或其他雜湊值進行驗證。此措施可降低檔案損壞風險，但不能絕對保證遠端來源始終可用。

9. 應用程式商店與付款

在相應平台提供本應用程式時，使用者透過應用程式商店購買本應用程式，例如 RuStore 或 Google Play。應用程式商店依其規則和隱私權政策獨立處理使用者帳戶、付款、退款、購買紀錄、安裝和更新。

若付款由應用程式商店處理，開發者不會取得使用者的銀行卡資訊、付款密碼或完整付款資訊。

10. 備份與匯出

備份僅會在使用者主動操作時建立。備份檔案可能包含應用程式中的大部分本機資料，包括鬧鐘、計劃、筆記、地理位置點、設定、診斷資訊及其他資料。

如果使用者透過其他應用程式、雲端儲存、電子郵件、即時通訊工具、檔案管理器或外部儲存媒體儲存或傳送備份，該檔案後續的保護與處理取決於使用者選擇的儲存或傳送方式。

11. 診斷

診斷日誌用於找出錯誤和檢查功能運作情況。日誌可能包含有關應用程式事件、時間、權限、裝置、作業系統版本、應用程式版本、鬧鐘、地理圍欄鬧鐘、筆記、備份狀態和錯誤的技術資訊。

診斷資料會儲存在本機，直至使用者將其清除或手動傳送給開發者。

12. 向第三方傳送

開發者不會向廣告商出售使用者資料，也不會自動向第三方傳送應用程式的本機資料。使用者主動使用外部服務、傳送支援請求、匯出備份、使用地圖、地理編碼、線上語音辨識、應用程式商店或其他外部服務時，可能發生資料傳送。

第三方服務依其自身規則處理資料。建議使用者查看其所選擇的應用程式商店、電子郵件服務、雲端儲存、地圖服務、語音辨識服務及其他外部服務的政策。

13. 資料保留期限

本機資料儲存在裝置上，直至使用者在應用程式內將其刪除、清除應用程式資料、刪除應用程式、從其他備份還原資料，或從所選儲存位置刪除備份檔案。

使用者傳送給開發者的支援請求、電子郵件、附件和診斷資料，可能在未預先設定固定期限的情況下保留，用於保留溝通紀錄、分析重複問題、保護權利和履行法定義務。使用者可以請求刪除這些資料；如果適用法律不再要求或允許繼續保留，開發者將執行該請求。

14. 安全

本應用程式使用 Android 的標準機制，包括作業系統對應用程式資料的隔離、系統權限和系統檔案選擇器。對於已實作相應驗證機制的檔案，部分下載檔案可透過雜湊值進行驗證。

使用者負責保護其裝置、螢幕鎖定、電子郵件帳戶、雲端服務、備份和外部儲存媒體。如果使用者將備份或匯出檔案儲存在未受保護的位置或傳送給第三方，其他人員可能存取這些檔案。

15. 資料處理所在國家或地區

本機資料會存在於使用者裝置所在及使用的國家或地區。透過應用程式商店、GitHub、地圖服務、語音辨識服務、電子郵件、雲端服務及其他外部服務傳送的資料，可能在這些服務營運或部署基礎設施的國家或地區處理。

傳送給開發者支援團隊的資料，可能在開發者所在地，或由開發者使用的電子郵件、代管或備份服務處理。

16. 使用者權利

使用者可以直接在應用程式內檢視、修改和刪除大部分資料。使用者也可以透過 Android 清除應用程式資料、刪除應用程式、撤銷權限、匯出備份，或刪除其建立的備份檔案。

對於使用者傳送給開發者的資料，使用者可以透過 support@insdeco.ru 聯絡開發者，並在適用法律賦予相關權利時，請求查閱、更正、刪除、限制處理或撤回同意。為保護資料，開發者可能要求提供必要資訊，以確認該請求與相應使用者或電子郵件地址有關。

如果使用者所在司法管轄區賦予其向資料保護主管機構申訴的權利，使用者可以依適用法律規定的程序向該機構提出申訴。

17. 兒童

本應用程式可能標示為 0+，但其設計目的並非由開發者專門蒐集兒童個人資料。兒童使用本應用程式時，如法律或家庭規則要求，父母或法定代理人應監督設定、權限、筆記內容、音訊錄音、地理位置點、備份和支援請求。

18. 政策變更

開發者可以更新本政策。目前版本可能隨應用程式一同提供、從遠端來源下載，或從內建備用版本開啟。發生重大變更時，如法律或應用程式邏輯要求，應用程式可能要求使用者重新閱讀政策或再次表示同意。
